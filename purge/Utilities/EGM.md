# Utilities

## Overview

`purge/Utilities` is a set of leaf-level, cross-feature helpers shared by scans, cleaning, the uninstaller, and the UI. It owns byte and date formatting, path-containment and file-identity checks, the subprocess runner used by `du`, `xcrun`, `xcode-select`, and `simctl`, Full Disk Access probing, Finder reveal/Quick Look/pasteboard actions, folder sizing, and small concurrency primitives.

The directory deliberately contains no deletion engine and no app-window routing. Its filesystem functions read, measure, reveal, or copy; the only file write in this directory is the debug trash log, while the test host redirects store writes to a scratch support directory. Several helpers are blocking by design (`ProcessRunner`, `FolderSizing`, `ConcurrentMap`, `DeveloperDirectory`), and the main-actor-only helpers (`FinderReveal`, `QuickLookPreview`) are explicitly annotated.

## Interface

**Byte, date, and size text**

- `formatBytes(_:)` (`ByteFormatter.swift:formatBytes(_:)`): `ByteCountFormatter` with `.useBytes`, `.useKB`, `.useMB`, `.useGB`, `.useTB`, `.file` count style, and units included; zero or negative input returns the localized "0 bytes".
- `formatStorageBytes(_:)` (`ByteFormatter.swift:formatStorageBytes(_:)`): one decimal at most, rounded to nearest, for storage-sidebar figures.
- `formatBytesRoundedDown(_:)` (`ByteFormatter.swift:formatBytesRoundedDown(_:)`): one decimal at most, truncated, for "up to" ceilings so a promise is never overstated.
- `formatOneDecimal(_:roundingDown:)` (`ByteFormatter.swift:formatOneDecimal(_:roundingDown:)`): decimal TB/GB/MB/KB thresholds and byte fallback; `byteCountFormatter` is the shared `nonisolated(unsafe)` formatter.
- `relativeDateText(for:referenceDate:)` (`RelativeDateText.swift:relativeDateText(for:referenceDate:)`): Today/Tomorrow/Yesterday, otherwise `RelativeDateTimeFormatter` output with its first character capitalized; `relativeDateFormatter` is the shared full-style formatter.
- `compactAgoText(from:to:)` (`RelativeDateText.swift:compactAgoText(from:to:)`): "just now", rounded tens of seconds under a minute, then minutes, hours, and days.
- `TimeTagline.timeText(for:)` (`TimeTagline.swift:TimeTagline.timeText(for:)`): sub-second durations show one decimal with a 0.1 minimum; under a minute shows rounded seconds; longer durations show `Xm Ys`.
- `CacheHeadline` (`CacheHeadline.swift:CacheHeadline`): `Pattern` (`.cache`, `.codeCache`, `.serviceWorkerCache`, `.serviceWorkerScriptCache`, `.oldVersion`), `pattern(of:cacheFolder:appFolder:)`, `localized(_:cacheFolder:appFolder:)`, `applicationSupportAppFolder(of:)`, and private `app(in:before:)`.

**Paths, containment, identity, and display**

- `PathContainment` (`PathContainment.swift:PathContainment`): `isSameOrInside(_:_:)`, `isInside(_:_:)` (never the root itself and boundary-aware), `containsSymlinkComponent(_:home:)` (lstat per component, fail-closed outside home), and `staysInside(root:url:home:includingRoot:)` (link-free root, root resolves to itself, URL resolves inside).
- `FileIdentity` (`FileIdentity.swift:FileIdentity`): `Hashable, Sendable` pair of `device` and `inode` from `stat`; `init?(path:)` follows symlinks and returns nil when the path cannot be read.
- `displayDirectoryPath(for:)` (`FilePathDisplay.swift:displayDirectoryPath(for:)`) and `abbreviatingHome(in:home:)` (`FilePathDisplay.swift:abbreviatingHome(in:home:)`): write home as `~` only on a real path boundary.
- `shortLocationLabel(for:)` (`FilePathDisplay.swift:shortLocationLabel(for:)`): the item's parent path with home and `~/Library` abbreviated, joining the remaining `~/Library/...` components with `›`.
- `appDisplayName(forBundleID:)` (`FilePathDisplay.swift:appDisplayName(forBundleID:)`) and `appNameWithoutExtension(_:)` (`FilePathDisplay.swift:appNameWithoutExtension(_:)`): resolve an installed app through `NSWorkspace` and strip a trailing `.app` from the localized display name.
- `AppSupportFolder.url()` (`AppSupportFolder.swift:AppSupportFolder.url()`): Purge's `io.getpurge.app` folder under Application Support, replaced by `TestHost.supportDirectory()` when the test host is active.

**Process execution and developer tools**

- `ProcessRunner` (`ProcessRunner.swift:ProcessRunner`): `Output` (`status`, `stdout`, `stderr`, `timedOut`, `succeeded`, `stdoutText`, `stderrText`); `run(executablePath:arguments:timeout:environment:)`; `runAsync(executablePath:arguments:timeout:environment:)`; private `terminationGrace = 2`, `pollSliceMilliseconds = 250`, `readBufferSize = 64 * 1024`, `drainPipes(...)`, `drainReadable(...)`, and `makeNonBlocking(_:)`.
- `DeveloperDirectory` (`DeveloperDirectory.swift:DeveloperDirectory`): `xcodeSelectPath = "/usr/bin/xcode-select"`, `Lookup` (`.found`, `.missing`, `.unanswered`), `active()`, `exists`, `resolve(launch:isDirectory:)`, and `Cache.active(launch:isDirectory:)` with a 10-second lookup timeout.
- `Simctl` (`Simctl.swift:Simctl`): `xcrunPath`, `frameworkDirectoryPath`, `frameworkPath`, `runtimeStorePath`, `userFolderRelativePath`, `Launcher` (`.xcrun`, `.framework`), `launcher(fileManager:)`, `resolveLauncher(developerDirectoryExists:launch:isExecutable:)`, `stillUsable(_:developerDirectoryExists:isExecutable:)`, `coreSimulatorPresent(fileManager:home:systemFolders:)`, `Runner`, `run(_:timeout:)`, `dispatch(_:timeout:launcher:launch:isExecutable:)`, `xcrunRefused(_:)`, `mentionsXcodeLicense(_:)`, and `runAsync(_:timeout:)`.

**Permissions and test host**

- `PermissionChecker` (`PermissionChecker.swift:PermissionChecker`): `hasFullDiskAccess()` probes `~/Library/Safari`, `~/Library/Containers`, and `~/Library/Application Support`; `canList(_:)` opens an enumerator with `.skipsSubdirectoryDescendants` and reads only the first entry.
- `TestHost` (`TestHost.swift:TestHost`): `isActive(environment:)` recognizes `XCTestConfigurationFilePath`, `XCTestBundlePath`, or `XCTestSessionIdentifier`; `supportDirectory()` returns a per-process, UUID-named temporary folder shared by one test run.

**Finder reveal, Quick Look, and the pasteboard**

- `ScanRowLocation` (`FinderReveal.swift:ScanRowLocation`): `url` plus optional `sizeBytes`.
- `FinderReveal` (`FinderReveal.swift:FinderReveal`, `@MainActor`): `show(_:)` reveals exactly one standardized URL through `NSWorkspace.shared.activateFileViewerSelecting`; `copyPaths(_:)` writes newline-joined standardized paths; `copyText(_:)` writes plain text; `menuTitle(for:)` shows the abbreviated path and size; `menuEntries(for:)` sorts locations by descending size and returns either a flat "Show in Finder" or a submenu, plus "Copy Path"/"Copy Paths".
- `QuickLookPreview` (`QuickLookPreview.swift:QuickLookPreview`, `@MainActor`): `show(url:)` standardizes the URL, sets it on the shared `DataSource`, assigns it to `QLPreviewPanel.shared()`, reloads, and orders the panel front.

**Folder sizing**

- `FolderSizing` (`FolderSizing.swift:FolderSizing`): `duChunkSize = 64`, `maxConcurrentDuChunks = 4`, process-wide `duChunkLimiter`, `duChunkTimeout = 300`, `limiterPollInterval = 100 ms`, `afterTakingPermit` task-local test hook, and `acquireDuPermit()`.
- `FolderSizing.Split` (`.fewest`, `.spread`), `chunks(of:split:)`, `directorySizesForChunk(_:)`, private `runDuChunk(_:staysOnVolume:)`, `directorySizes(at:split:staysOnVolume:onChunkSizes:onChunkDone:)`, `directoryByteSize(at:)`, `directoryByteSizeIfMeasurable(at:staysOnVolume:)`, `walkedSize(at:skipsPackages:isCancelled:)`, `singleFileSize(at:)`, and `contentModificationDate(at:)`.
- `SizeComparisonCatalog` (`SizeComparisonCatalog.swift:SizeComparisonCatalog`): `Phrasing` (`.counted`, `.timesOver`), `Anchor`, `anchors`, `item(for:)`, private `displayLabel(for:multiplier:)`, `stableIndex(for:count:)`, and `formatCount(_:)`. Thresholds: 5 MB minimum, multiplier 1...20,000, ideal multiplier 2, score tolerance 0.3.
- `OnboardingSizeComparisonItem` (`OnboardingSizeComparison.swift:OnboardingSizeComparisonItem`) and `OnboardingSizeComparison.items(for:)` (`OnboardingSizeComparison.swift:OnboardingSizeComparison.items(for:)`): zero or one catalog item.
- `LifetimeSizeComparison.item(for:)` (`LifetimeSizeComparison.swift:LifetimeSizeComparison.item(for:)`): direct catalog lookup.

**Concurrency and diagnostics**

- `ConcurrentMap.values(_:width:_:)` (`ConcurrentMap.swift:ConcurrentMap.values(_:width:_:)`): preserves input order, runs at most `min(max(1, width), items.count)` lanes through `DispatchQueue.concurrentPerform`, and omits the parallel path when only one lane is needed.
- `CancellationFlag` (`ConcurrentMap.swift:CancellationFlag`): lock-protected `isRaised` and `raise()` for work running outside a Swift task.
- `ResumeOnce<Value>` (`ResumeOnce.swift:ResumeOnce`): lock-protected single resume of a `CheckedContinuation<Value, Never>`; later calls do nothing; `resume()` convenience for `Void`.
- `TrashDebugLog` (`TrashDebugLog.swift:TrashDebugLog`): `fileURL` at `AppSupportFolder.url()/trash-debug.log`, serial `queue`, shared `formatter`, and `log(_:)` with an `@autoclosure` message.
- `ScanPhaseTiming` (`ScanPhaseTiming.swift:ScanPhaseTiming`): debug-only `log(_:)` with a `PURGE-TIMING:` prefix, `elapsed(since:)`, and `finish(_:since:detail:)`.
- `SupportNudge` (`SupportNudge.swift:SupportNudge`): `url`, milestone constants, defaults keys, `milestone(lifetimeBytes:cleanBytes:defaults:)`, `showsFooterLink(cleanBytes:now:defaults:)`, `recordShown(milestoneBytes:now:defaults:)`, `recordLinkOpened(defaults:)`, `Line`, `CleanFacts`, `lines(for:)`, and `selectLine(for:now:defaults:)`.

## Invariants

- **Formatting never overstates a size.** `ByteFormatter.swift:formatBytes(_:)` and all helpers return "0 bytes" for zero or negative input. `formatBytesRoundedDown(_:)` truncates rather than rounds, because a ceiling must be something the measured result can meet (`ByteFormatter.swift:formatOneDecimal(_:roundingDown:)`). `formatBytes(_:)` uses nearest rounding and is not suitable for an "up to" promise.
- **Path containment is boundary-based, not string-prefix-based.** `PathContainment.swift:isInside(_:_:)` appends `/` to the root before comparing, so `/Users/a/Library2` is not inside `/Users/a/Library`. Both sides must already be standardized and have no trailing slash; the file documents this precondition.
- **Symlink checks fail closed.** `PathContainment.swift:containsSymlinkComponent(_:home:)` returns true when the URL is not under home as well as when any component is a link; it `lstat`s each step and never follows. `staysInside(root:url:home:includingRoot:)` also rejects a root that is reached through a link or whose resolved path differs from the literal root, so a link inside the root cannot redirect a delete.
- **File identity is the filesystem's identity.** `FileIdentity.swift:init?(path:)` uses `stat`, so links are followed and `/var` and `/private/var` or differently-cased spellings of the same item compare equal through their device and inode. A failed `stat` yields nil rather than a fabricated identity.
- **Home abbreviation never invents a path.** `FilePathDisplay.swift:abbreviatingHome(in:home:)` abbreviates only when `PathContainment.isInside(_:_:)` holds, avoiding the `/Users/alice2` → `~2` mistake. `appNameWithoutExtension(_:)` removes only a trailing `.app` of a name longer than four characters.
- **`ProcessRunner` uses argv, never a shell.** `ProcessRunner.swift:run(executablePath:arguments:timeout:environment:)` assigns `executableURL` and `arguments` directly to `Process`; there is no shell, command string, or interpolation layer, so callers cannot inject shell syntax through a path. `environment`, when supplied, replaces the inherited environment whole.
- **`ProcessRunner` avoids the three classic `Process` hangs.** `standardInput` is `FileHandle.nullDevice`; both pipes are made non-blocking and drained with `poll(2)` on the calling thread; the wait escalates from `terminate()` (SIGTERM) to `kill(..., SIGKILL)` after `terminationGrace` (2 seconds) and abandons with `timedOut: true` if a grandchild keeps the pipes open. `timedOut` makes `status` meaningless, and `run` returns nil only when the binary could not launch.
- **`ProcessRunner` must not block the main queue.** `ProcessRunner.swift:run(...)` contains a `dispatchPrecondition(condition: .notOnQueue(.main))` in DEBUG; synchronous callers must be off the main actor, and `runAsync(...)` dispatches to `DispatchQueue.global(qos: .utility)`.
- **`DeveloperDirectory` never runs a shim blindly.** `DeveloperDirectory.swift:DeveloperDirectory` only runs `/usr/bin/xcode-select -p`, which is not a shim and never shows the install dialog. A definite `.found` or `.missing` answer is cached for the process; `.unanswered` is never cached because one slow cold start must not disable developer tools until quit. A cached `.found` path is re-checked on disk on every `active()` call, because Purge can trash Xcode while running.
- **`Simctl` only uses `xcrun` when a developer directory exists.** `Simctl.swift:resolveLauncher(developerDirectoryExists:launch:isExecutable:)` checks `DeveloperDirectory.exists` before running `/usr/bin/xcrun --find simctl`, because the shim would otherwise show the Command Line Tools install dialog (#298). It falls back to the CoreSimulator framework copy when the developer-directory check or `xcrun --find simctl` does not succeed and that copy is executable; `stillUsable(_:developerDirectoryExists:isExecutable:)` downgrades a cached `.xcrun` after Xcode disappears.
- **`xcrun` failure only triggers a framework retry when `simctl` never started.** `Simctl.swift:xcrunRefused(_:)` requires a non-timeout, non-zero exit and stderr beginning with `xcrun: error:` or mentioning the Xcode license; `dispatch(...)` then retries the framework copy only if it is executable, otherwise keeps xcrun's diagnostic.
- **Full Disk Access is the only permission probe.** `PermissionChecker.swift:hasFullDiskAccess()` requires all three protected Library locations to be listable. `PermissionChecker.swift:canList(_:)` reads only the first entry, treats an empty folder as readable and a missing folder as unreadable, and never lists user content folders; callers must not list Downloads/Documents/Desktop before this returns true, or macOS shows per-folder TCC prompts.
- **Tests never touch the user's real app data.** `TestHost.swift:isActive(environment:)` recognizes the XCTest environment keys, and `AppSupportFolder.swift:url()` returns `TestHost.supportDirectory()` in that case. `TestHost.swift:supportDirectory()` is one UUID-named temporary folder per process/run, so stores that would write to Application Support write there instead (#185).
- **Finder reveal is one URL per call.** `FinderReveal.swift:show(_:)` is `@MainActor` and passes a single standardized URL to `NSWorkspace.shared.activateFileViewerSelecting`; the file documents that multiple URLs fan out one Finder window per parent. Multi-location rows use `menuEntries(for:)` and reveal the chosen location.
- **Quick Look is main-actor and single-item.** `QuickLookPreview.swift:QuickLookPreview.show(url:)` is `@MainActor`, sets a standardized URL on the shared data source, and the data source always reports one preview item.
- **Sizing concurrency is process-wide and bounded.** `FolderSizing.swift:maxConcurrentDuChunks = 4` and `duChunkLimiter` are shared across all callers, not per invocation. `directorySizesForChunk(_:)` and `directorySizes(...)` take a permit with a cancellation-aware timed wait, call `afterTakingPermit` for tests, and release the permit in `defer`/the dispatched block even when cancelled. A caller that already holds a permit must call `runDuChunk(_:staysOnVolume:)` directly; calling `directorySizesForChunk(_:)` again would deadlock when the cap is full.
- **`du` output is parsed, not trusted as a fixed total.** `FolderSizing.swift:runDuChunk(_:staysOnVolume:)` runs `/usr/bin/du -sk` (or `-skx` when `staysOnVolume`), parses tab-separated kilobytes, multiplies by 1024, and keeps partial output from a timed-out or non-zero run. A chunk that cannot launch yields no entries, which callers treat as zero via `directoryByteSize(at:)`.
- **The two split policies have different accounting.** `FolderSizing.swift:Split.fewest` keeps up to 64 folders per `du`, so a hard-linked file is counted once across the chunk and the Trash total keeps that meaning. `.spread` gives each process roughly one folder for small lists, so hard-linked files can count in two folders; the file explicitly says no safety level or gate reads those scan sizes.
- **`walkedSize` is cancelable and package-aware.** `FolderSizing.swift:walkedSize(at:skipsPackages:isCancelled:)` sums `totalFileAllocatedSize ?? fileSize` in-process, tracks the latest access or modification date, and asks `isCancelled` between files. It must be called with `skipsPackages: false` for virtual machines whose disk folders can register as packages. `directoryByteSizeIfMeasurable(at:staysOnVolume:)` distinguishes "no reading" (`nil`) from a measured zero, while `directoryByteSize(at:)` maps nil to 0.
- **`ConcurrentMap` preserves order and requires independence.** `ConcurrentMap.swift:values(_:width:_:)` writes results by input index under a lock, uses `width` (defaulting to `ProcessInfo.processInfo.activeProcessorCount`) capped to at least one and at most the item count, and runs directly when only one lane is needed. `transform` must not depend on another item's result. The function blocks the caller, so it belongs off the main actor, and `Task.isCancelled` is false on its threads; callers that need cancellation pass a `CancellationFlag` raised from `withTaskCancellationHandler`.
- **`ResumeOnce` resumes exactly once.** `ResumeOnce.swift:resume(returning:)` takes the continuation under a lock and clears it before resuming, so a reply, error handler, and timeout can race without a double resume.
- **Support nudges have bounded frequency.** `SupportNudge.swift:milestone(lifetimeBytes:cleanBytes:defaults:)` requires a positive clean, lifetime greater than the clean, no prior link opening, at least 100 GB lifetime, and a milestone strictly above the last shown one (100 GB, then every 50 GB). `showsFooterLink(cleanBytes:now:defaults:)` requires at least 2 GiB and a seven-day cooldown. `selectLine(...)` avoids the immediately previous line when another fits and records the pick. Once `recordLinkOpened(...)` sets its flag, neither card nor line returns.
- **Size comparisons are deterministic and under-promise.** `SizeComparisonCatalog.swift:item(for:)` returns nil below 5 MB, uses counts rounded down with a minimum of 1, caps multipliers at 20,000, and picks among at most the three anchors within 0.3 log10 of the best fit. `stableIndex(for:count:)` hand-mixes the byte count because Swift's `Hasher` is seeded per process, so the same size always yields the same line.
- **Debug logging is compiled out of release.** `TrashDebugLog.swift:log(_:)` and `ScanPhaseTiming.swift:log(_:)` wrap their work in `#if DEBUG`; release builds neither build the message nor write or print. `TrashDebugLog` writes to Purge's Application Support folder, not `~/Library/Logs`, because `~/Library/Logs` is a cleaning target, and it re-ensures the directory on every write. Its `DateFormatter` is used only on the serial `queue`.
- **Main-actor boundaries are explicit.** `FinderReveal.swift:FinderReveal` and `QuickLookPreview.swift:QuickLookPreview` are `@MainActor`; `ProcessRunner`, `FolderSizing`, `ConcurrentMap`, `DeveloperDirectory`, and `Simctl` are blocking and must be called off the main actor, with `ProcessRunner` enforcing that in DEBUG.

## Side Effects

- **Subprocess launches:** `ProcessRunner.swift:run(...)` launches the executable at `executablePath` with argv; `FolderSizing.swift:runDuChunk(_:staysOnVolume:)` launches `/usr/bin/du`; `DeveloperDirectory.swift:resolve(launch:isDirectory:)` launches `/usr/bin/xcode-select -p`; `Simctl.swift:dispatch(...)` launches `/usr/bin/xcrun simctl ...` or the CoreSimulator `simctl` binary. `ProcessRunner` sends SIGTERM and then SIGKILL to a child that overruns its timeout.
- **Threads, queues, and locks:** `FolderSizing` creates per-chunk serial `DispatchQueue`s named `purge.folder-sizing.du` and blocks in `DispatchGroup.wait()`; `ConcurrentMap` uses `DispatchQueue.concurrentPerform`; `CancellationFlag`, `ResumeOnce`, `DeveloperDirectory.Cache`, and `Simctl` use `NSLock`; `ProcessRunner.runAsync` and `Simctl.runAsync` dispatch blocking work to global utility queues.
- **File-system reads:** `PermissionChecker.hasFullDiskAccess()` enumerates three protected Library locations; `FileIdentity.init?(path:)` calls `stat`; `DeveloperDirectory` stats the selected developer directory; `Simctl.coreSimulatorPresent(...)` checks framework, runtime-store, and user-folder existence; `FolderSizing.walkedSize(...)`, `singleFileSize(at:)`, and `contentModificationDate(at:)` read resource values; `TrashDebugLog` reads/creates its log file.
- **File-system writes:** `TrashDebugLog.swift:log(_:)` creates the Application Support directory and appends a timestamped line to `trash-debug.log` in DEBUG builds only. `AppSupportFolder.url()` and `TestHost.supportDirectory()` only choose paths; they do not create them.
- **Finder, Quick Look, and pasteboard:** `FinderReveal.show(_:)` asks `NSWorkspace` to open a Finder window; `FinderReveal.copyPaths(_:)` and `copyText(_:)` clear and write `NSPasteboard.general`; `QuickLookPreview.show(url:)` assigns a data source and orders a `QLPreviewPanel` front as key window.
- **User defaults:** `SupportNudge` reads and writes `supportNudge.lastShownMilestoneGB`, `supportNudge.didOpenLink`, `supportNudge.lastShownAt`, and `supportNudge.lastShownLine` in the supplied `UserDefaults` (`.standard` by default). No other file in this directory touches user defaults.
- **Localized text and AppKit lookups:** `CacheHeadline`, `ByteFormatter`, `TimeTagline`, `RelativeDateText`, and `SizeComparisonCatalog` call localization APIs; `FilePathDisplay.appDisplayName(forBundleID:)` asks `NSWorkspace` for the installed app and `FileManager.displayName(atPath:)`.
- **No deletion, move, network, or XPC:** no file in this directory deletes or moves user files, opens a network connection, or speaks XPC. Finder reveal only selects an item in Finder.
