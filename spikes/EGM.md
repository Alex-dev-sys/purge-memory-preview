# Spikes

## Overview

Standalone experiments kept outside the shipping app targets. The Apple Intelligence model spike explores an asset-management path and records assumptions used by the separate `PurgeAssetWorker` target.

## Subdirectories & Boundaries

- [apple-intelligence-models](./apple-intelligence-models/EGM.md) - Swift package and Objective-C bridge experiment for inspecting Apple Intelligence asset behavior.

## Verification

- No repository-wide test command is defined for these experiments; use the package-specific instructions in the child contract when intentionally working on a spike.
